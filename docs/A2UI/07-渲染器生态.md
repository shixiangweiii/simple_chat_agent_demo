### 共享 Web Core (v0.9)

v0.9 引入统一的 Web 渲染核心库，所有 Web 渲染器共用：

```
A2UI JSON → 共享 Web Core (解析 + 虚拟 DOM) → React / Angular / Lit 适配器 → 实际 DOM
```

优势：
- 同一份 A2UI 输出可被任何 Web 框架渲染
- 减少 React/Angular/Lit 渲染器间的行为差异
- 新框架只需写适配器层

### B站 Vue 渲染器

B站商业广告团队基于 A2UI 协议构建了完整的 Vue 渲染器和 Agent 工具链，用于广告投放助手、产品帮助助手、数据分析助手。

**架构特点**：
- **Runtime Schema 组装**：每个业务动态组件白名单
- **双重验证机制**：结构验证（消息类型、组件白名单、属性完整性、Action 白名单）+ 过渡验证（Surface 状态机一致性）
- **SSE 双通道输出**：文本聊天流 + A2UI Surface 更新并行
- **Wrapper 组件扩展**：业务组件通过 Vue Wrapper 注册到 Catalog
- **从模板迁移**：从基于模板的方法（`::: ProductCard :::`）迁移到 A2UI 生成式 UI

**设计经验**：
- 双层验证对生产使用至关重要
- Catalog 设计应使用业务/场景级组件（如 `AddressForm`、`RefundCard`），而非原子原语
- Surface 状态机防止 Agent 生成非法状态序列

### Jetpack Compose 渲染器 (a2ui-compose)

中国 Android 开发者创建的开源 Jetpack Compose 渲染器，因为 Google 官方路线图将其列为"计划中"。

**4 层架构**：

```
A2UIRenderer (Composable)       ← 顶层入口
    ↓
18 种组件类型 (Text, Button, Card, Tabs...)  ← 组件映射
    ↓
Engine (SurfaceManager + DataModel + FunctionRegistry)  ← 状态管理
    ↓
Parser + Network (JSONL/SSE + OkHttp)  ← 传输层
```

**18 种组件**：Text、Button、Card、Tabs、Row、Column、List、Image、Icon、Divider、TextField、CheckBox、DateTimeInput、Slider、Modal、Rating、Video、自定义组件

**14 个内置函数**：required、email、formatDate、parseNumber 等

**DataModelManager**：通过 JSON Pointer 和双向绑定管理组件数据

发布时间：2026-03-24

### 鸿蒙 AGenUI

高德地图团队开发的 HarmonyOS (ArkTS) A2UI 渲染器。

**特点**：
- 完整的 SSE 客户端在鸿蒙上实现（手动 UTF-8 解码 + 协议解析）
- Surface 生命周期管理与聊天消息列表的集成
- 支持 Markdown / Chart / Lottie 组件渲染
- GitHub: https://github.com/AGenUI/AGenUI

发布时间：2026-05-31

## 7.3 CopilotKit 集成

CopilotKit 提供了 **A2UI Composer** 工具，用于可视化构建 A2UI 组件：

- URL: https://a2ui-composer.ag-ui.com/
- 可视化拖拽构建 A2UI 组件树
- 自动生成 A2UI JSON 输出
- 与 AG-UI 协议集成

这体现了 A2UI 与 AG-UI 的互补关系：AG-UI 提供传输管道，A2UI 提供组件描述格式。

| .NET 生态 | Blazor Renderer | 实验性 |

## 7.5 Macaron A2UI — 生成式 UI 模型

Mind Lab (Macaron AI 的研究实验室) 开源了 **Macaron A2UI** 系列 LoRA 适配器模型，专门用于生成式 UI：

- 模型接收对话上下文作为输入，输出符合 A2UI v0.8 协议的结构化 JSON 卡片
- 三个规格，覆盖从轻量到旗舰
- 2026 年 6 月，Mind Lab 发布 Macaron-V1-Preview (749B 参数, 激活 40B, 基于 GLM5.1)，在 A2UI 协议评测中取得开源模型 SOTA

这表明 A2UI 不仅是一个协议规范，也在推动"UI 生成模型"这一新范式。
