# ATA 官方技能

ATA 官方接口，包含文章搜索、文章详情、消息推送等能力；可查询各种技术解决方案、架构设计、先进技术等内容，以及订阅 ATA 相关内容信息。

ATA 是阿里技术生态体系内部的工程师交流平台，着力于工程师技术交流协作和工程师文化培养，提供文章、专题、圈儿、活动组织等功能。

网址：https://ata.atatech.org/

# FAQ

## 蚂蚁的同学提示： failed to obtain CIAP credential: failed to parse nos CLI output: invalid character 'E' looking for beginning of value

当然蚂蚁同学遇到 nsc关键字、让登陆阿里郎之类的问题一般都是这个原因

这个原因是你安装了 `a1`插件，这个插件会有别名`aone-kit`，覆盖了真正的`aone-kit`。 然后`a1`是基于`阿里郎`
的，所以蚂蚁没法使用。  
直接执行，删除别名即可：

```shell
rm -rf ~/.local/bin/aone-kit
```
